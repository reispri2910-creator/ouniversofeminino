O UNIVERSO FEMININO - COMO COLOCAR O SITE NO AR COM FRETE DOS CORREIOS (MELHOR ENVIO)

O QUE TEM NESTA PASTA
- index.html ............... o site
- img/ ..................... fotos dos produtos
- netlify/functions/frete.js  função que consulta o frete no Melhor Envio sem expor o seu token
- netlify.toml ............. avisa a Netlify onde está a função

ATENÇÃO: arrastar a pasta na Netlify Drop publica o site, mas pode NÃO publicar a função do frete.
Sem a função, o site mostra uma estimativa de frete (tabela ENVIO no index.html). Para o frete real,
publique pelo GitHub ou pelo Netlify CLI (passo 4).

PASSO 1 - Conta e token no Melhor Envio
1. Crie sua conta gratuita em melhorenvio.com.br e complete o cadastro (CPF ou CNPJ é obrigatório para envios pelos Correios).
2. No painel, na barra lateral esquerda, clique em Integrações e depois em Permissões de Acesso
   (em algumas contas esse menu aparece como Área Dev).
3. Clique em GERAR NOVO TOKEN, marque "Li e concordo" e avance.
4. Dê um nome ao token (por exemplo, Site loja), marque Selecionar todos (ou ao menos Cotação de fretes) e clique em GERAR TOKEN.
5. Copie o token na hora: ele só aparece uma vez. Se perder, gere outro.
   O token é uma senha: não mande para ninguém e não cole dentro do index.html.
   Para testar sem gastar nada, existe o ambiente de testes: sandbox.melhorenvio.com.br (conta separada, token separado).

PASSO 2 - Variáveis na Netlify
Em Site configuration > Environment variables, crie:
- ME_TOKEN ..... o token do passo 1
- ORIGEM_CEP ... o CEP de onde você envia os pedidos
- ME_CONTATO ... seu e-mail
- ME_AMBIENTE .. escreva sandbox só se estiver testando com o token de testes (deixe sem essa variável em produção)

PASSO 3 - Peso e medidas
No index.html, na lista PRODUTOS, ajuste para cada produto:
- peso (em gramas, com a embalagem)
- dim: [largura, altura, comprimento] em centímetros, com a embalagem
O frete é calculado com esses números. Se estiverem errados, o valor cobrado do cliente vai ficar diferente do que você paga.

PASSO 4 - Publicar com a função
Opção A (recomendada): GitHub
1. Crie um repositório no GitHub e envie esta pasta.
2. Na Netlify: Add new project > Import an existing project > escolha o repositório. Não precisa de comando de build.
Opção B: Netlify CLI
1. Instale o Node.js e rode: npm install -g netlify-cli
2. Dentro desta pasta: netlify login, depois netlify deploy --prod

TESTE
Abra o site publicado, adicione um produto, digite um CEP de outra cidade e toque em Calcular.
Devem aparecer PAC e SEDEX com valor e prazo. CEP de Três Lagoas - MS mostra frete grátis.
Compare um valor com o simulador do Melhor Envio para conferir.

ENTREGA GRÁTIS EM TRÊS LAGOAS
Já está configurada. Para mudar, edite ibgeGratis e cepGratis na lista ENVIO do index.html.
